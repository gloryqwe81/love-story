# Сайт «Для тебя, любовь моя»

Интерактивная романтическая история с фотогалереей, любовным письмом,
анимациями, музыкой и автоматической публикацией в GitHub Pages.

## Куда положить фотографии и песню

- Фотографии: `public/media/photos/`
- Песня: `public/media/music/our-song.mp3`

Фотографии должны называться:

`photo-01.jpg`, `photo-02.jpg`, `photo-03.jpg`, `photo-04.jpg`,
`photo-05.jpg`, `photo-06.jpg`.

Подробная короткая инструкция находится в файле
[`MEDIA-INSTRUCTIONS.md`](./MEDIA-INSTRUCTIONS.md).

## Как изменить текст

Все фразы, подписи к фотографиям и любовное письмо собраны в одном файле:

`app/content.ts`

## Локальный запуск

```bash
pnpm install
pnpm dev
```

## Публикация

После загрузки проекта на GitHub включите в настройках репозитория:

`Settings → Pages → Source → GitHub Actions`

Каждое обновление ветки `main` будет автоматически публиковать новую версию.
